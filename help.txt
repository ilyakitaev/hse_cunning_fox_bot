СПРАВКА ПО БОТУ

Этот бот предоставляет доступ к RAG-системе с использованием ассистентов.

КОМАНДЫ:

/start - приветственное сообщение и краткое описание
/help - эта справка
/auth <пароль> - авторизация для доступа к системе
/assistants - список доступных ассистентов

ПРИВАТНЫЕ КОМАНДЫ (доступны после авторизации):

/collections - список коллекций в базе данных
/collection_create <имя> - создать новую коллекцию
/prompts - список системных промптов
/prompt_create <имя> -- <содержание> - создать новый промпт
/prompt_show <id> - показать данные промпта
/prompt_update <id> -- <содержание> - обновить промпт
/assistant_create <имя> <коллекция> <prompt_id> - создать нового ассистента

УПРАВЛЕНИЕ ДАННЫМИ:

/data_list <коллекция> - показать список записей в коллекции
/data_show <коллекция> <id> - показать содержимое записи
/data_remove <коллекция> <id> - удалить запись из коллекции
/data_remove_all <коллекция> - удалить все записи из коллекции
/data_add_bulk <коллекция> - начать массовую загрузку (интерактивный режим)
/done - завершить массовую загрузку
